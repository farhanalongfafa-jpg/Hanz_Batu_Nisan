Shared constraints in each generation: photorealistic luxury automotive campaign treatment; authentic Malaysian marker proportions; solid flat stone slab; no Western semicircular tombstone, crosses, plinth or invented construction; no letters, Arabic, quotations or symbols. Portrait assets show the full object with breathing room. No existing photograph was used as a website asset.

The collection lineup is composed in HTML using the three generated assets. Engraving examples remain live HTML overlays so text is accurate, editable and translated. Finish buttons are preference selectors, not photorealistic material simulations. Final physical specifications require business confirmation.

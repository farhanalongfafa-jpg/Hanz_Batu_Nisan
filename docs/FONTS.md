# Typography

Panchang Bold and Switzer Regular by Indian Type Foundry, downloaded from the official Fontshare CSS and CDN for self-hosted use.

Source: https://www.fontshare.com/
Fontshare licensing information: https://www.fontshare.com/licenses

Panchang is used for the HANZ wordmark; Switzer for campaign and interface text. System Arial fallback prevents invisible text while the fonts load. The classic engraving choice uses the system Georgia serif as a user-selected preview style.
